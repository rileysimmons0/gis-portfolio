# Riley Simmons GIS Portfolio

A responsive, forest-green GIS portfolio for GitHub Pages.

## GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Set **Source: Deploy from a branch**.
3. Choose **main** and **/(root)** and save.
4. Visit https://rileysimmons0.github.io/gis-portfolio/ after it deploys.

## Images to add
The homepage code is already in `index.html`. To show your original coastal photo and matching forest footer, upload these files from your starter ZIP to the repository's `assets` directory, using **Add file → Upload files**:

- `assets/coastal-photo-original.jpg` — original photo, unchanged. The gradient and contour lines are added by website code.
- `assets/forest-footer.png` — matching forest footer.

Add `assets/resume.pdf` for the resume button.

## Customize
Edit `index.html` to replace placeholder LinkedIn and contact details, and add screenshots of your GIS projects. The project tiles are currently stylized placeholders; only publish municipal datasets/screenshots that you're allowed to share.

The site uses no framework or build step.
